# Event Detail & Tickets (Sub-projects 1 + 2) — Design Spec

## Goal

Build an event detail screen shared across Connect and Discover, with free RSVP that generates an in-app ticket (card + QR code), and a My Tickets section in Grow.

## Scope

This spec covers **sub-projects 1 and 2 only**:
- Event detail screen (all events, free only for now)
- Free RSVP → instant ticket generation
- In-app ticket view (TicketCard component)
- Google Calendar deeplink
- My Tickets section in Grow

Paid checkout, ticket email, and payment gateway are separate specs (sub-projects 3 + 4).

---

## Architecture

**Approach:** Shared route + DB-generated ticket code. One screen at `/app/event/[id].tsx` used by both Connect and Discover. Postgres generates collision-safe ticket codes on insert. No edge function needed for free events.

**New package:** `react-native-qrcode-svg` — Expo-compatible SVG QR renderer, no native modules.

## Data Layer — Migration 020

### `events` table additions
| Column | Type | Default | Purpose |
|---|---|---|---|
| `is_private` | boolean | false | Private = community members only; hidden from Discover |
| `is_paid` | boolean | false | Reserved for sub-project 3; allows "Free" / "Paid" badge on cards |

### `event_attendees` table additions
| Column | Type | Default | Purpose |
|---|---|---|---|
| `ticket_code` | text UNIQUE | `'ROXY-' \|\| upper(substr(gen_random_uuid()::text, 1, 8))` | Human-readable ticket reference, generated by Postgres on insert |

### Query filter changes
- **Discover events query**: add `.eq('is_private', false)` — private events never appear in Discover
- **Connect events query**: already filtered by joined community IDs — private events naturally scoped

## Event Detail Screen — `/app/event/[id].tsx`

### Layout (content-first, no hero image)

```
← Back

  WLW Social Mixer                    ← large title
  🏳️‍🌈 Queer Manila                     ← community name, tappable → community detail

  🗓  Sat 12 Apr · 7:00 – 9:00 PM
  ⏱  2 hours                          ← derived from ends_at - starts_at; hidden if ends_at null
  📍  The Garden Bar, Manila           ← tappable → Linking.openURL(location_url) if set
  👥  42 going                         ← attendee_count
  🎟  Free                             ← or "Paid" when is_paid true

  About
  Long description text...             ← ScrollView, no line limit

  ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─      ← only visible after RSVP

  🎟️ Your Ticket                       ← only visible after RSVP
  [TicketCard]

  [ + Add to Calendar ]               ← only visible after RSVP; Google Calendar deeplink

  [ RSVP — It's Free ]                ← becomes "You're going ✓  ·  Cancel" after RSVP
```

### RSVP flow

1. User taps "RSVP — It's Free"
2. Optimistic: button disabled, shows loading indicator
3. `INSERT INTO event_attendees (event_id, user_id, status='going') RETURNING ticket_code`
4. `setTicketCode(code)` — ticket section animates in with `Animated.spring`
5. Button becomes "You're going ✓ · Cancel"
6. Cancel: `DELETE FROM event_attendees WHERE event_id AND user_id`, hide ticket section

### Data fetch on mount

```ts
supabase
  .from('events')
  .select('*, communities(id, name), profiles!host_id(display_name)')
  .eq('id', eventId)
  .single()
```

Check existing RSVP on mount:
```ts
supabase
  .from('event_attendees')
  .select('ticket_code, status')
  .eq('event_id', eventId)
  .eq('user_id', userId)
  .maybeSingle()
```

If row exists → pre-populate `ticketCode`, show ticket section immediately.

### Google Calendar deeplink

Built from event fields, opened with `Linking.openURL()`. No library needed.

```
https://calendar.google.com/calendar/render
  ?action=TEMPLATE
  &text=<title>
  &dates=<starts_at_utc>/<ends_at_utc>   (format: YYYYMMDDTHHmmssZ)
  &location=<location_text>
  &details=Roxy+event+·+<community_name>
```

If `ends_at` is null, use `starts_at + 1 hour` as fallback end time.

## My Tickets Section — Grow Screen

Added to the Grow ScrollView below existing sections. Hidden entirely if user has no upcoming tickets.

### Data fetch

```ts
supabase
  .from('event_attendees')
  .select('ticket_code, events(id, title, starts_at, location_text, communities(name))')
  .eq('user_id', userId)
  .eq('status', 'going')
  .order('events.starts_at', { ascending: true })
  .limit(5)
// Filter upcoming only: events.starts_at >= now (post-filter in JS)
```

### Layout

```
My Tickets  (3) →            ← count of total going tickets; taps → future full list screen (out of scope)
┌──────────────┐ ┌──────────────┐ ┌──────────────┐
│ 🌸 Going     │ │ 🌸 Going     │ │ 🌸 Going     │
│ WLW Social   │ │ Queer Book   │ │ Pride Picnic  │
│ Mixer        │ │ Club         │ │               │
│ Sat 12 Apr   │ │ Sun 20 Apr   │ │ Fri 2 May    │
│ 7:00 PM      │ │ 3:00 PM      │ │ 12:00 PM     │
└──────────────┘ └──────────────┘ └──────────────┘
```

- Horizontal `ScrollView` (`horizontal` prop)
- Each card taps → `/event/[id]` where full TicketCard with QR is shown
- Compact card: no QR (QR lives on detail screen only)
- "See All (N) →" taps → same `/event/[id]` of first ticket for now (full list screen is sub-project 5)

## Event Card Changes (Connect + Discover)

Both screens: tapping the event card body navigates to `/event/[id]`. The RSVP/Interested button stays on the list row for quick action without opening detail.

```tsx
// Card body becomes a TouchableOpacity
<TouchableOpacity onPress={() => router.push(`/event/${item.id}` as any)} activeOpacity={0.8}>
  {/* date chip, title, community, location */}
</TouchableOpacity>
// RSVP button stays outside, does not propagate tap to card
```

Discover also adds `.eq('is_private', false)` to its events query.

---

## Error Handling

- Event not found (deleted): show "This event is no longer available" with a back button
- RSVP insert fails: revert optimistic state, show brief toast
- Location URL missing: tapping 📍 opens nothing (button non-tappable when `location_url` is null)
- `ends_at` null: hide duration row; Google Calendar uses `starts_at + 1 hour`
