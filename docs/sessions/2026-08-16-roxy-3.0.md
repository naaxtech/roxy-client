# Roxy 3.0 — what moved where

Session date: 2026-08-16 · Branch: `redesign/roxy-3.0` · Design: `docs/handoff/roxy-3.0/`

Five tabs collapse to four plus a create action. **Nothing is deleted.** Every
screen below is moved or merged, and this table is the gate: a route folder is
removed only after every row that lives in it is reachable in ≤2 taps from its
new home. A row that cannot be reached is a bug in the redesign, not a reason to
keep the folder.

`app/user/[userId]`, `app/community/[id]`, `app/chat/[id]`, `app/sister-button`,

## Known gaps, carried deliberately

- **Ticket tiers.** The prototype shows per-tier pricing; the schema has one
  `events.price_cents` per event and no tiers table. Shipped single-price.
- **Mute.** The prototype offers mute alongside block; the app has never had
  mute. Shipped block + report + local hide, and the screen says "Blocked".
- **Unblock.** Blocking works through the `block_user` RPC; there is no unblock
  RPC, so the blocked list ships read-only with an honest note.
- **Following feed segment.** No follow graph exists; the segment is backed by
  the friend graph and says so in its empty state.
- **Second dating-mode writer.** `app/(tabs)/connect/index.tsx` writes
  `profiles.is_dating_mode` directly instead of through `profileStore.updateProfile`.
  It dies with the Connect folder; until then the two paths can disagree.
