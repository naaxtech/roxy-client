## Known gaps, carried deliberately

- **Ticket tiers.** The prototype shows per-tier pricing; the schema has one
  `events.price_cents` per event and no tiers table. Single-price is the plan.
- **Mute.** The prototype offers mute alongside block; the app has never had
  mute. Block + report + local hide is the whole surface, and the screen should
  say "Blocked" rather than implying a mute exists.
- **Following feed segment.** No follow graph exists, so the segment is backed
  by the friend graph and its empty state says so instead of looking broken.
- **Create sheet: four of five rows are disabled.** Only Post has a composer in
  this app; events, rooms, products and games are authored in Roxy Studio. Each
  row says so rather than opening a "coming soon" toast, because a ＋ button
  that lies is a ＋ button she stops pressing.
- **Second dating-mode writer.** `app/(tabs)/connect/index.tsx` writes
  `profiles.is_dating_mode` directly instead of through
  `profileStore.updateProfile`, so the two paths can disagree. It dies with the
  Connect folder in phase 8; if phase 8 slips, fix the writer on its own.
- **The pink button carries dark ink.** The prototype paints `#FFF8FB` on the
  pink fill, which measures 3.75:1 and fails for a button label. `inkOn()` picks
  `#1A0A2E` at 4.75:1 instead. This is the one deliberate visual departure from
  the design, and it is visible on every primary button.
